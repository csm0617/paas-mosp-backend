# Triage Labels

五个规范 triage 角色在本仓的字面标签（本仓暂未实际使用 triage 流程，先按默认值登记）。

| 角色 | 本仓标签 | 含义 |
| --- | --- | --- |
| needs-triage | `needs-triage` | 待维护者评估 |
| needs-info | `needs-info` | 等报告人补充信息 |
| ready-for-agent | `ready-for-agent` | 规格完整，可交给 AFK 智能体 |
| ready-for-human | `ready-for-human` | 需要人来实现 |
| wontfix | `wontfix` | 不处理 |

技能提到某个角色时，用本表对应的标签字符串。
