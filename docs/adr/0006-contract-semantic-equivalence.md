# 契约比对判定标准：语义等价

**Status: accepted**（2026-10-14，工单 08 的落定；采纳"语义等价"，并逐条追认已记录偏离）

## 决定

**契约比对按"语义等价"判定**，**不是**逐字节等价，**也不是**"能渲染就算过"。三层判定的含义由本 ADR 定死：

| 层 | 判什么 | 不绿算什么 |
| --- | --- | --- |
| **L1 形状** | 信封 `{msg, code, data}`；前端会读的每个键**存在**；键的类型按**值**判等价（数字比数值，不比 JSON 节点类型） | **缺陷，必须修** |
| **L2 前端读取路径** | `docs/findings/read-paths.json` 里列出的字段路径 + 值（含写路径的表单字段） | **缺陷，必须修** |
| **L3 已知偏离** | client-java 的显式 `null` 噪声、厂商自造键 `proxy`、fabric8 多出的新 K8s 字段 | **记录在案**，不要求补齐 |

**关键的第四条规则（把"语义等价"和"弱判定"区分开）**：L3 里任何一条偏离，一旦被证明**前端可见**（前端读了它、或它导致渲染/交互变化），立刻**升级为 L1/L2 缺陷**。也就是说 L3 不是"可以不管"的抽屉，而是一份**带原因的、每次新域上线都要重看的**差异账。

## 为什么否掉另两个选项

- **逐字节等价**（选项 2）：代价全部花在前端看不见的键上——`03`/`09` 号证据已验明 19 个单项键里 7 个前端**从不读**（含 `runningDeployment`、`fixedName`、`imageInfo`）。更致命的是它不脆：厂商的 null 噪声来自 client-java 的 `V1*` 模型，K8s 加字段就会漂移。**它把一个会漂移的第三方实现细节锁成了验收标准。**
- **弱判定**（选项 3）：只要求"页面能渲染、不报错"。它省掉了 L1/L2 的字段存在性判定，等于放弃"契约"这条门槛本身（ADR-0004 第 1 条）。**它拦不住"表格少一列"这类破坏**——页面照样渲染，只是数据没了。

## 已追认的偏离（工单 08 要求逐条裁定）

`docs/findings/read-paths.json` 中 `GET /v1/service` 的两条 `allowDeviation`，**全部追认**：

| 键 | `deviationKind` | 裁定理由 |
| --- | --- | --- |
| `restartCount` | `display-equivalent` | 两侧取值口径不同但**页面显示的语义相同**；前端只把它渲染成一个数字。不追认就得复刻厂商由 client-java 侧算出的中间值，属于把实现细节当契约。 |
| `mappingInfo` | `at-least-as-complete` | 我们比厂商**更完整**（厂商在部分行给空）。偏离方向是"信息更多"，前端不会因此渲染错。**反向不允许**：我们给空而厂商给值时，会升级为缺陷。 |

**`deviationKind` 的语义也随之定死**：`display-equivalent` = 值与厂商不同但页面表现一致；`at-least-as-complete` = 我们给的信息是厂商的超集。**只有这两类可被追认**，其它任何偏离要么是缺陷，要么必须先新增一类并说明。

## L3 差异账的处置

L3 的差异**记录在案**，逐条写进 `read-paths.json` 的 `knownDeviations`（键 + 原因 + 处置），并随域扩展。当前三条：client-java 的显式 `null` 噪声、厂商自造键 `proxy`、fabric8 多出的较新 K8s 字段。

**未定论的一条**：`proxy` 键是否被前端读取——尚未在产物里检索到字面量 `proxy` 的读路径；若后续证明前端读它，按上面的第四条规则升级为 L1 缺陷。**该条写进 `read-paths.json` 时不得标成永久豁免。**

## Consequences

- `tools/contract-check.py` 与 `mvn test` 里的离线契约用例是**同一套判定**，两者必须同步演进；新增偏离只能通过改 `read-paths.json` 生效，不允许在代码里写特例。
- 每上线一个新域，必须回看 L3 差异账一次（新域的键可能落在旧账上）。
- "语义等价"的举证责任在我们这边：**任何"我们不一样但没关系"的说法，都要指出前端哪一行读它、以及为什么页面表现不变**，否则不许写进 `allowDeviation`。
